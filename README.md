IoT Deception Honeypot Network
Overview

This project simulates vulnerable IoT devices to attract attackers and analyze malicious behavior. The honeypot captures brute-force attacks, payload uploads, attacker commands, and network activity.

Features
IoT Device Simulation
Cowrie Honeypot Deployment
Attack Logging
Threat Intelligence Extraction
Geolocation Analysis
Splunk Dashboard Visualization
Technologies Used
Cowrie
Honeyd
Docker
Python
Splunk
Linux Ubuntu
Installation

pip install -r requirements.txt

Run Project

python attack_parser.py
